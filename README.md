# 🤖 المساعد رشيد (Rashid Help)

بوت تيليجرام لحماية وإدارة المجموعات، يعمل بالعربية، ومصمم للعمل في عدة مجموعات في نفس الوقت تحت إدارتك الكاملة.

## ✨ المميزات

- **إشراف وإدارة:** كتم، حظر، طرد، إنذارات (تلقائي بعد 3 إنذارات)، حذف رسائل، حذف جماعي، تثبيت/إلغاء تثبيت.
- **قفل/فتح المجموعة:** إغلاق وفتح المناقشة بأمر واحد.
- **الحماية من السبام:** كلمات محظورة قابلة للإضافة من داخل المجموعة، منع الروابط، كشف التكرار (Flood) وكتم المخالف تلقائيًا.
- **نظام ردود تلقائية كامل:** إضافة/حذف/عرض ردود مخصصة لكل مجموعة (نص، صورة، فيديو، ملصق، ملف) مع أزرار شفافة — كل ذلك من داخل المجموعة بدون لمس الكود.
- **رسالة ترحيب** قابلة للتخصيص للأعضاء الجدد.
- **قوانين مجموعة** قابلة للتعيين والعرض.
- **لوحة تحكم خاصة بالمالك** (أنت فقط) عبر أمر `/admin` في الخاص مع البوت: عدد المجموعات + بث رسالة لكل المجموعات دفعة واحدة.
- **متعدد المجموعات:** أضف البوت لأي عدد من المجموعات بنفس الحساب، كل مجموعة لها إعداداتها المستقلة (قوانين، ردود، كلمات محظورة... إلخ).

> ملاحظة مهمة: الأوامر الجاهزة (كتم/حظر/...) ثابتة في الكود. أما "الإضافات من داخل البوت" المقصودة هنا هي **نظام الردود التلقائية** (`اضف رد` / `حذف رد` / `ردود`) الذي يتيح لك ولأي مشرف إضافة كلمات/جمل جديدة يرد عليها البوت تلقائيًا بدون أي تعديل في الكود أو إعادة تشغيل. إضافة أوامر برمجية جديدة (غير الردود) تتطلب تعديل الكود ورفعه من جديد.

## 📋 قائمة الأوامر

راجع رسالة `/help` داخل البوت، أو ملف `bot/handlers/general.py`.

## 🔧 المتطلبات قبل التشغيل

1. **Python 3.11+**
2. **توكن بوت تيليجرام** من [@BotFather](https://t.me/BotFather):
   - أرسل له `/newbot` إن لم يكن البوت `@Rashid_Help_bot` مُنشأ مسبقًا (هو موجود بالفعل بالاسم الذي ذكرته)، أو `/token` لاسترجاع توكن بوت موجود.
   - **لا تشارك هذا التوكن مع أي شخص أو في أي محادثة** — أي شخص يحصل عليه يتحكم الكود بالكامل في البوت بدلاً منك.
3. **آيديك الرقمي (OWNER_ID):** `5750213326` (كما أرسلته) — هذا هو من سيملك لوحة التحكم الخاصة `/admin`.
4. رفع صلاحيات **مشرف كامل** للبوت في كل مجموعة تريد حمايتها (حذف رسائل، حظر أعضاء، تثبيت رسائل، دعوة أعضاء عبر الرابط).

## ⚙️ التشغيل محليًا / على سيرفر

```bash
git clone <رابط المستودع>
cd Rashid-Help-
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# افتح .env وضع فيه:
#   BOT_TOKEN=التوكن الحقيقي من BotFather
#   OWNER_ID=5750213326

python run.py
```

البوت يعمل بنظام **Polling** (لا يحتاج رابط عام/سيرفر ويب)، لذلك يمكن تشغيله على أي جهاز أو VPS متصل بالإنترنت ويبقى يعمل باستمرار (يُفضّل استخدام `systemd` أو `pm2` أو `screen`/`tmux` لإبقائه يعمل بعد إغلاق الطرفية).

## 🔐 أمان

- لا تضع التوكن أو أي مفتاح API داخل الكود مباشرة — استخدم ملف `.env` فقط (موجود ضمن `.gitignore` ولن يُرفع لجيت هب).
- إن تم تسريب التوكن في أي وقت (مشاركته، لقطة شاشة، إلخ) — أرسل `/revoke` لـ @BotFather فورًا للحصول على توكن جديد.
- قاعدة البيانات (`rashid_help.db`) تحوي بيانات المجموعات والإنذارات والردود؛ لا تُرفع لجيت هب أيضًا (مستثناة في `.gitignore`).

## 🗂 بنية المشروع

```
bot/
  config.py        # قراءة التوكن والإعدادات من .env
  db.py             # قاعدة بيانات SQLite (مجموعات، إنذارات، حظر، كتم، ردود، كلمات ممنوعة)
  utils.py          # دوال مساعدة (تحليل المدة، تحديد العضو الهدف...)
  filters.py        # فلاتر صلاحيات (مشرف المجموعة / المالك)
  handlers/
    moderation.py   # كتم/حظر/طرد/إنذار/حذف/تثبيت/قفل/فتح...
    antispam.py      # كلمات محظورة، منع الروابط، الحماية من السبام
    replies.py        # نظام الردود التلقائية القابل للتوسعة من داخل المجموعة
    welcome.py         # رسالة ترحيب الأعضاء الجدد
    general.py          # /start /help /id
    owner_panel.py        # لوحة تحكم المالك الخاصة /admin
run.py                      # نقطة تشغيل البوت
```
